# 开机提示回归测试

在 Linux 或 WSL 中，从仓库根目录运行：

```sh
python3 submodules/uefi/tests/test_boot_warning.py
```

需要 Python 3、Clang（含 ASan/UBSan）和 liblzma 开发库。工具与样本输出均位于临时目录，不刷机、不写真实分区。

覆盖实际 C 实现的默认关闭、设置持久化、512／4096 字节块设备、旧默认项与自定义项位置兼容、读写及刷新失败；验证加载流程的开关传递、真实锁状态判断、只读文件访问、短读处理及错误资源释放；覆盖 PE 地址转换、截断／损坏输入、歧义匹配、函数边界及失败不修改缓冲区。使用仓库 13 份 ABL 样本的两种修补模式，验证支持的镜像只修改提示分支，不支持的镜像明确拒绝。

测试中的块设备和 UEFI 库替身只用于主机验证，不能替代实际固件的加载、按键与屏幕显示验证。
